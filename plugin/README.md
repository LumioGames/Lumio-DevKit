# Lumio DevKit

Lumio 游戏开发者与 Agent 共用的使用手册。插件标识 `lumio-devkit`，本轮版本 `0.3.0`。

| 任务 | Skill |
| --- | --- |
| 环境、目录、能力导航、升级引擎 | [公共基础](skills/lumio-development/SKILL.md) |
| 共享 Gameplay、实体、同步、GAS、Tick | [Gameplay](skills/lumio-gameplay/SKILL.md) |
| 输入、连接、同步、客户端调试 | [客户端](skills/lumio-client/SKILL.md) |
| 启动、世界、存档、服务端调试 | [服务器](skills/lumio-server/SKILL.md) |
| 地图、读写、加载、物理查询 | [体素](skills/lumio-voxel/SKILL.md) |
| 编辑、导出、生成 Reader、双端读取 | [配置表](skills/lumio-config/SKILL.md) |
| 制作、导出、交接、接入验收 | [美术](skills/lumio-art/SKILL.md) |

从当前任务所需的技能进入，不必一次读取整本手册。先看 [能力与限制](skills/lumio-development/references/capabilities.md) 和 [验证记录](VERIFICATION.md)，区分接口存在、局部检查和真实宿主运行。
