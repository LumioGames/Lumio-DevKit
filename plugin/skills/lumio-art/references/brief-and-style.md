# 简报、风格与协作

用于从需求进入制作，或在美术与开发之间对齐一次改动。项目已经有可用规范时，先复用对应条目；不为换一个图标重做整套风格。

## 把玩法需求翻译成画面要求

先找设计稿、实际界面或当前场景，填齐影响制作的条件。缺值标为待确认，不用猜测填成引擎限制。

| 条件 | 需要形成的决定 | 为什么影响制作 |
|---|---|---|
| 玩家判断 | 看见后应知道什么、采取什么动作 | 决定信息优先级，避免装饰替代必要信息 |
| 出现场景 | HUD、面板、世界内对象，是否被遮挡 | 决定背景、层级和状态表达 |
| 镜头与尺度 | 固定或自由镜头，常见及最远观察距离，实际显示尺寸 | 决定轮廓、细节和屏幕占比 |
| 状态变化 | 可交互、不可交互、选中、等待、成功或失败中哪些适用 | 决定变体及程序消费条件 |
| 目标环境 | 实际浏览器、设备、视口、输入方式 | 决定验证环境，不能只看美术工作站 |
| 风格依据 | 当前规范版本、同组已验资产、参考及反例 | 让修改有共同标准 |
| 消费与交接 | 谁接、在哪里加载、接受什么文件、怎样复验 | 及早发现格式或渲染能力缺口 |

交付的是一份能指导制作的简报，不要求固定文档系统。小任务可写在项目现有资产记录中；多批生产建议单独保存规范并引用版本。

## 风格还没有确定时

在用户给定题材与产品范围内比较少量有实质差异的方案。每个方案说明轮廓、材质表现、光色、UI 语言如何帮助玩家判断，以及制作、修改和接入成本。不要仅列审美形容词。

把参考拆解成可执行观察：采用其层级关系或轮廓节奏，不表示照搬角色、标志或整张构图。为容易产生歧义的要求提供反例。无现成参考时可用文字、布局草图或项目现有资产开展讨论，不必启动图像生成。

把选定方向写成可对照条目，例如：

- 「可交互物必须在常用镜头下与背景分开」落实为明度、外轮廓或辅助标记的对照样品。
- 「同类图标看起来是一组」落实为相同观察角度、视觉重量、留白与状态处理。
- 「危险不能只靠颜色识别」落实为同时保留轮廓、图案或文字提示，并在实际背景上检查。

这些是条目写法示例，不是替所有游戏规定一种画风。需要数值时写明来源：项目选择、测量结果或已验证的消费限制；不要给一个习惯值冠以引擎标准。

先把选中的方向放入最关键的玩法画面，确认信息能读、素材能接、修改成本可接受，再扩成批量规范。用户已明确方向时直接推进；涉及推翻既有视觉身份的取舍，应说明返工范围再确认方向。

## 一份小简报示例

下面是虚构项目的一次 UI 需求；数值与命名都是该示例的项目选择。

> **任务**：为维修面板提供「修理」动作图标。
>
> **玩家判断**：区分可执行、材料不足和执行中；不能将执行中理解为失败。
>
> **使用环境**：桌面浏览器，面板深浅两种背景；图标显示为 32 CSS px，旁边保留动作文字。
>
> **风格依据**：沿用现有工具栏的轮廓、视觉重量与留白，先与相邻两个图标并排检查。
>
> **本次范围**：一个基础符号及状态示意；数字、进度与文本由界面绘制。
>
> **工作假设**：按钮宿主可显示图片，焦点环由控件负责；接入负责人需先确认加载方式。
>
> **首件判断**：实际大小可分辨；材料不足仍看得清；执行中状态与程序状态一致。
>
> **交付**：可编辑源、已验证格式的导出物、状态映射说明、来源记录与浏览器截图。

先验证基础符号，不在消费方式未确认时批量输出所有分辨率或整套图集。

## 美术、开发与 Agent 如何合作

| 责任 | 具体交回物 |
|---|---|
| 美术或风格负责人 | 可修改源、状态示意、导出说明、视觉判据与修改理由 |
| 客户端接入负责人 | 实际消费入口、支持的参数、失败信息、屏幕中的验证结果 |
| 玩法负责人 | 状态的真实含义、体素与实体归属、交互和碰撞要求 |
| Agent | 整理缺口、维护映射和版本、在授权范围内编辑与验证、区分观测和推断 |

一人可以承担多项责任，不需要人为增加审批角色。Agent 提交修改意见时应附资产版本、问题位置、出现条件、依据和最小修改建议，避免「感觉不够好」式反馈。已授权的常规调整可以直接推进；影响玩法、风格方向或分发权限的变化分别交由其负责人决策。

如需生成提示词，包含用途、主体、项目风格依据、镜头与构图、必须保留的识别特征、需要避免的元素和交付用途。按实际工具写参数；未验证的模型版本、种子或参考控制能力不承诺复现。提示词、生成原稿和人工修改分别留记录；采用与否按最终资产验收。

遇到导入能力缺失，把问题写成「需要消费什么、现有入口缺什么、最小验证如何做」，继续完成不依赖它的源文件或样品。能力判断方式见 [能力说明](../../lumio-development/references/capabilities.md)。
